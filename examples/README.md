# Examples

This directory is reserved for small, focused examples that demonstrate how to use MQL5 Engineering without turning the repository into a collection of trading strategies.

Good examples should:

- illustrate one workflow, auditor, invariant, scenario, or validation pattern;
- use minimal source material;
- avoid proprietary strategy code;
- avoid profitability claims;
- state what is demonstrated and what is intentionally not validated;
- remain useful across compatible Agent Skills runtimes where practical.

Examples may include:

- a minimal EA used to demonstrate DEBUG routing;
- an execution-lifecycle example for `OnTradeTransaction` reasoning;
- a risk-sizing example paired with deterministic helper output;
- a release-readiness example with a completed release report;
- a focused indicator-data example using `CopyBuffer` and synchronization checks.

Do not include live credentials, broker account data, paid strategy code, or customer source code without explicit permission.
