# UI auditor

Apply only when UI exists. Verify controls, states, labels, numerical values, pause/start/close semantics, error/connectivity feedback, stale data, and design-source consistency. Compare displayed state, configured state, and actual trading state. Verify chart-object naming, creation/deletion lifecycle, `OnChartEvent` safety, and `ChartRedraw` discipline.

Reference: `references/ui-design.md`.
